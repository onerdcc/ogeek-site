# OGeek Site

Site estático para publicação no GitHub e implantação no EasyPanel.

- `/` abre a página principal (`index.html`).
- `/fire.html` abre o tutorial Fire TV.

## EasyPanel

1. Envie o conteúdo desta pasta para a raiz do repositório `onerdcc/ogeek-site`.
2. Crie um serviço conectado ao repositório no EasyPanel.
3. Use a opção de build por Dockerfile (arquivo `Dockerfile`) e publique o serviço na porta 80.
4. Vincule o domínio desejado ao serviço.
